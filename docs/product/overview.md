# AVX Informática — Overview de Producto

Última actualización: 2026-03-20

## Objetivo

Construir un sitio corporativo que demuestre capacidad técnica antes de describirla, usando una identidad espacial fuerte y una demo arcade como prueba de ejecución.

## Qué debe comunicar el sitio

1. AVX puede construir software con criterio técnico real.
2. AVX cuida experiencia, rendimiento y detalle.
3. AVX no vende humo visual; ejecuta.

## Stack

- HTML5
- CSS3
- JavaScript ES modules
- Canvas 2D API
- SVG

Sin frameworks ni librerías de UI.

## Estados del sitio

- `home`: experiencia principal de escritorio.
- `game`: demo arcade.
- `fallback`: vista reducida para viewport insuficiente.

## Viewport mínimo para juego

- ancho mínimo: `1024px`
- alto mínimo: `600px`

## Alcance vigente

- El home y fallback están implementados en nivel MVP.
- Las secciones `nosotros`, `servicios`, `portafolio` y `contacto` ya están integradas como contenido real.
- El juego está implementado parcialmente.
- El formulario de contacto aún no está implementado.
