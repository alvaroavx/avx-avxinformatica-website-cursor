SECCIÓN 03 // PORTAFOLIO

Proyectos donde la complejidad era real.

CORFO, Poder Judicial, Universidad de Chile, Dirección del Trabajo, ADRetail, Blue Express y banca. No mostramos conceptos: mostramos ejecución.

01 Plataforma de Gestión de Metadatos para CORFO CORFO · 2025 · Python / Django / PostgreSQL / DSpace 7

Problema: publicación manual, dispersa y sin trazabilidad en DSpace.

Qué construimos: plataforma completa con workflow de aprobación, DataTables avanzado, exportaciones, API por API Key e integración automatizada paso a paso con DSpace 7.

Impacto: flujo único, repetible y trazable; eliminación de pasos manuales.

02 Administrador de Sentencias del Poder Judicial Poder Judicial · 2017–2018 · Django / Solr / VuFind / OAI-PMH

Problema: más de 10 millones de sentencias dispersas y difíciles de encontrar.

Qué construimos: pipeline de cosecha y normalización, índice de búsqueda con facetas, backoffice de curación e integración con SSO institucional.

Impacto: búsquedas que pasaron de horas a milisegundos y operación diaria automatizada.

03 Gestión Tributaria e Integración con SII CORFO · 2023–2024 · .NET / SQL Server / SOAP / REST / EPPlus

Problema: consultas fiscales masivas requerían intervención manual y tiempos altos.

Qué construimos: plataforma web, API de Carpeta Tributaria con caché inteligente y consola para lotes de RUTs con Excel y envío automático por correo.

Impacto: validación masiva automatizada, reducción de tiempos y trazabilidad completa.

04 Normalización Masiva de Metadatos DSpace Universidad de Chile · 2024 · Python / PostgreSQL / pandas / fuzzywuzzy

Problema: más de 366.000 registros sin normalizar degradaban la búsqueda del repositorio.

Qué construimos: sistema de fuzzy matching con procesamiento paralelo para agrupar variantes de autores, asesores y editores.

Impacto: 166.234 registros estandarizados y mejor recuperación de información científica.

05 MiBO: BackOffice Institucional Dirección del Trabajo · 2019–2020 · React / Redux / Node.js / SQL Server

Problema: trámites internos fragmentados sin un sistema core institucional unificado.

Qué construimos: backoffice completo con workflows, modelado BPM, notificaciones, trazabilidad y soporte multicanal.

Impacto: base del nuevo sistema core institucional con procesos digitalizados a nivel país.

06 OMS Omnix / Proyecto Sirius ADRetail · 2020–2021 · AWS / Lambda / Docker / Magento / Node.js

Problema: integrar eCommerce, OMS y operación omnicanal en retail de alto volumen.

Qué construimos: arquitectura serverless en AWS, conectores, integración OAuth 2.0, pipeline PMM → Magento y apoyo a implementación WMS.

Impacto: sincronización diaria automatizada y trazabilidad completa de órdenes.

07 Modernización Sistema OJS Universidad de Chile · 2024 · OJS / PHP / jsPDF / XML / Quill

Problema: errores críticos impedían validación SciELO y faltaban capacidades editoriales modernas.

Qué construimos: corrección de XML, ORCID, afiliaciones, multilenguaje, PDF/HTML desde XML, editor WYSIWYG y formatos de citación múltiples.

Impacto: cumplimiento de estándares SciELO y mejor experiencia para editores e investigadores.

08 Gobierno de APIs y Microservicios Blue Express · 2021–2022 · NestJS / Spring Boot / EKS / Kong / Keycloak

Problema: necesidad de estandarizar servicios, seguridad y despliegues en Kubernetes.

Qué construimos: gobierno API First, integración con Kong y Keycloak, CI/CD con GitHub Actions y Helm, y arquitectura GraphQL con Redis Pub/Sub.

Impacto: catálogo de servicios estandarizado, despliegues reproducibles y seguridad unificada.

09 APIs Financieras ADRetail · 2021–2024 · NestJS / Docker / Kubernetes / Cognito / Apigee

Problema: modernizar sistemas financieros legacy y exponer capacidades críticas con seguridad.

Qué construimos: OTP, login, movimientos, avances VISA, firma SOVOS, cuentas y transferencias, y apificación de legados con alta cobertura de pruebas.

Impacto: continuidad operativa, trazabilidad del cliente y modernización del core financiero.

10 Capacitación Angular Práctico Capacitación técnica · 2025 · Angular v20 / TypeScript / RxJS

Problema: equipo necesitaba subir nivel en Angular moderno y arquitectura escalable.

Qué construimos: programa intensivo de 24 horas con aplicación modular de RRHH, validaciones, arquitectura, interceptores y evaluación práctica.

Impacto: equipo con capacidad real para desarrollar Angular moderno con mejores prácticas.
